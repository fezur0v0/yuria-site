# Friend directory fonts

Self-hosted using `next/font/local`, scoped to the friend directory.

- Anton, regular 400: Google Fonts subset for uppercase Latin letters and digits.
  Source: https://fonts.google.com/specimen/Anton — `Anton-OFL.txt`.
- Noto Serif SC, weight 500: Google Fonts text subset for the Chinese title,
  existing friend name and description, and short editorial copy.
  Source: https://fonts.google.com/specimen/Noto+Serif+SC — `NotoSerifSC-OFL.txt`.

- Noto Serif KR, weight 500: only the three Korean glyphs in 칼바람.
  Source: https://fonts.google.com/specimen/Noto+Serif+KR — `NotoSerifKR-OFL.txt`.

Update the Noto Serif SC subset when adding new Chinese display text. The
functional controls and addresses use the site's existing Geist fonts.
